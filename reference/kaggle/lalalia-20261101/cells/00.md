# ARC-AGI-3: Franzen Milestone 2 + cache-safe solved-level memory

Submission notebook documented in our **ARC Prize 2026 Paper Track** writeup, *"Luck, Tokens and Memory: What Moves a
Single-GPU LLM Agent on ARC-AGI-3"* (lalalia9). Public leaderboard score of this notebook: **31.46**.

**What it is.** [Daniel Franzen's Milestone 2 solution](https://www.kaggle.com/code/dfranzen/arc-agi-3-milestone-2-solution)
(Tufa Labs' Duck harness, Qwen3.8-Flash-Next W4A16 on Pennyroyal SGLang) with its prompts and serving configuration
**unchanged**, plus one harness change, injected in the customization cell (`SOLVED_LEVEL_MEMORY_PATCH`):

- When a level is cleared, the harness records facts it already has: the level number, actions used, the winning
  attempt's last 30 actions and the tail of the reasoning in the turn that cleared it. It then asks the model, in
  the next two turn messages, for one `Rule for level N:` line, captured from its reply or reasoning.
- These records are pinned as one block at the **end** of the system prompt, so the shared start of the prompt stays
  identical across games.
- The block is only rewritten when a history trim already forces the server to re-read the conversation, so the
  prefix cache is never invalidated by it (measured hit rate 94.3%, unchanged throughput).

Our measurements (public-game simulations and repeated leaderboard draws) are in the writeup. In short:
efficiency changes such as compacting per-turn prompts or running 12 streams instead of 10 looked neutral on public
games but cost ~7-8 points on the hidden games, so this notebook keeps Franzen's configuration and adds only memory.
