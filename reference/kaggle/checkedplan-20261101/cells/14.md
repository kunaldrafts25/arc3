## 6. Pennyroyal / SGLang — GPU Inference Server Setup

В этой ячейке устанавливается и запускается оптимизированный inference-сервер Pennyroyal на базе SGLang, который обеспечивает работу языковой модели агента на GPU. Код создаёт изолированную Python-среду, настраивает CUDA и проверяет совместимость основной модели Qwen3.8-Flash-Next с квантованной MTP draft model. Для ускорения генерации используются speculative decoding, CUDA Graphs, оптимизированный KV-cache и параллельная обработка запросов. После загрузки моделей запускается локальный сервер, а специальная проверка `/health` отслеживает его готовность к выполнению игровых задач.
