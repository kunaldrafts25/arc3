## 5. Source Bundle Integration — Python Import Configuration

В этой ячейке подключаются исходные репозитории Duck Harness и связанные компоненты из ранее подготовленного source bundle. Код автоматически находит доступные Python-модули и добавляет их пути в `sys.path`, чтобы notebook мог импортировать необходимые классы и функции. Дополнительно создаётся файл `.pth`, который делает эти модули доступными для дочерних процессов, включая отдельные компоненты системы агента. Этот этап обеспечивает правильную интеграцию исходного кода без необходимости устанавливать каждый репозиторий как отдельный Python-пакет.
