## 4. ARC Runtime Installation — Offline Dependencies

В этой ячейке устанавливается официальный пакет `arc-agi`, необходимый для взаимодействия агента с игровыми средами ARC-AGI-3. Все зависимости загружаются из локального набора установочных файлов Kaggle, поскольку во время официального evaluation доступ к интернету отключён. Установка выполняется в тихом режиме, чтобы не перегружать notebook техническими сообщениями, но реальные ошибки остаются видимыми. Этот этап подготавливает игровой движок и API, через которые агент будет получать состояния среды и выполнять действия.
