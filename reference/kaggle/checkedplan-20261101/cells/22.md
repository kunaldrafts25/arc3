## 10. Benchmark Execution — Offline Testing & Competition Submission

В этой ячейке запускается основной процесс тестирования агента на игровых средах ARC-AGI-3. Код автоматически определяет режим выполнения: при локальном запуске используются доступные offline environments, а во время официальной отправки агент подключается к соревновательному шлюзу Kaggle и получает список игр непосредственно от него. Затем запускается benchmark, который управляет параллельным прохождением игр, выполнением действий и сбором результатов в пределах установленного времени. После локального тестирования создаётся технический файл `submission.parquet`, необходимый для Kaggle, однако он содержит только заглушку и не отражает реальный результат агента — фактическую эффективность необходимо оценивать по диагностике benchmark.
